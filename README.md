# Automotive Console – Elevating Vehicle Data Management

## 📌 Overview

An automotive console developed using a PIC microcontroller for monitoring vehicle-related data.

The system monitors temperature and battery-related information using ADC-based data acquisition and displays the information in real time on an LCD. A frost-alert feature provides a safety indication when the temperature reaches the defined condition.

## 🎯 Objectives

* Monitor temperature
* Monitor battery-related data
* Acquire sensor data using ADC
* Display real-time information on an LCD
* Provide frost-alert safety indication

## 🔧 Components Used

* PIC Microcontroller
* Temperature Sensor
* LCD Display
* Battery
* ADC

## 💻 Technologies

* Embedded C
* PIC Microcontroller
* ADC
* LCD Interfacing
* Sensor Interfacing
* Embedded Systems

## ⚙️ Working

1. The PIC microcontroller acts as the main controller.
2. Temperature and battery-related data are collected.
3. ADC is used for data acquisition.
4. The processed information is displayed on the LCD.
5. A frost-alert indication is provided when the temperature reaches the defined condition.

## ✨ Key Features

* Temperature monitoring
* Battery monitoring
* ADC-based data acquisition
* Real-time LCD display
* Frost-alert safety indication
